# Franklin — Finance and Economics Video Workshop

Working repository for researching, developing, and writing videos for **Franklin**, a mascot-led YouTube channel about economics, financial systems, personal finance, and financial history.

Franklin explains ideas that are often made needlessly intimidating. The target viewer already understands basic investing vocabulary but should not need a finance degree, an economics textbook, or a Bloomberg terminal to follow a video.

| `ideas/backlog.md` | Idea bank. Each entry needs an arguable thesis and a viewer-facing reason to care. |

## Default production loop

1. Capture a topic in `ideas/backlog.md` as a tension, not merely a subject.
2. Choose one precise thesis and identify the belief or confusion the video will change.
3. Build a claim ledger using `reference/research-standards.md`.
4. Stress-test the argument with the strongest competing explanation.
5. Outline from `reference/script-template.md`.
6. Preserve the creator's raw judgments, cautions, preferred comparison, intended reveal, and optional jokes.
7. Draft the factual and structural script from evidence, outline, creator notes, and relevant voice samples.
8. Diagnose specific voice drift with the Franklin rubric.
9. Make one targeted voice revision rather than repeatedly polishing the whole script.
10. Read aloud and add accepted spontaneous substitutions to `reference/voice-corpus.md`.
11. Run the production and packaging audit.
12. Move approved scripts from `scripts/drafts/` to `scripts/final/`.

When documents conflict, `AGENTS.md` wins. Factual accuracy and public-information boundaries override style, pacing, and punchlines.
