# 05 — Rights and Download Checklist

This checklist protects both legal usability and historical honesty. It is not legal advice; platform and institution terms can change.

## Before downloading

- [ ] Open the individual asset page, not only a search result.
- [ ] Confirm the creator/uploader, title, item ID, source institution, and current licence.
- [ ] Confirm commercial YouTube use is allowed.
- [ ] Check for recognizable people, trademarks, artwork, architecture, or private-property restrictions.
- [ ] Prefer the highest-resolution original offered by the source.
- [ ] Save the source page URL and licence URL.
- [ ] Take a PDF or screenshot of the rights statement with the date.
- [ ] Record any required attribution verbatim.
- [ ] Record whether cropping, color treatment, animation, and compositing are allowed.
- [ ] Rename the file with its manifest ID immediately.

## Primary-document checklist

### A01/A02 — Bibliothèque de Genève via e-rara

- [ ] Reconfirm the holding institution and shelf marks: Gf 1341/3/2303 and Gf 1341/3/2304.
- [ ] Verify that the high-resolution endpoints still correspond to the correct pages.
- [ ] Read the current [e-rara terms of use](https://www.e-rara.ch/wiki/termsOfUse).
- [ ] Contact BGE/e-rara if the rights statement on the item page is ambiguous for monetized documentary use.
- [ ] Ask whether cropping, zooming, underlining, and color correction are permitted.
- [ ] Preserve the item record and required credit line in `09_RIGHTS_RECEIPTS/`.
- [ ] Verify every spoken name against the scan; OCR is not authority.

Suggested credit, subject to confirmation:

`Bibliothèque de Genève, Gf 1341/3/2303, via e-rara`

### A03 — Cramer article

- [ ] Treat the PDF primarily as a research source.
- [ ] Use only small, legible excerpts necessary for commentary.
- [ ] Cite author, title, journal, year, and page.
- [ ] Avoid uploading the full PDF into the public repo or redistributing it.
- [ ] If a large page reproduction is central, ask the journal/publisher about permission.

### A04 — Met Anne Audéoud bust

- [ ] Download through the [Met object page](https://www.metmuseum.org/art/collection/search/199036), which marks the image Public Domain.
- [ ] Save both available views if useful.
- [ ] Record object number 42.23.2 and the exact title.
- [ ] Do not remove the narration/on-screen clarification that Anne is from the wider circle and not the January 1782 list.
- [ ] Do not alter her facial features; crop, isolate, and move the public-domain image only.

Suggested credit:

`The Metropolitan Museum of Art, object 42.23.2 — Public Domain`

### A05/A06 — Commons/Gallica historical images

- [ ] Use the individual file page to identify the exact licence.
- [ ] For A05, prefer the original Gallica/source-institution file if its reuse terms are clearer.
- [ ] If using the Commons crop of A05, comply with the stated CC BY-SA 4.0 requirements and indicate modifications.
- [ ] A06's file page currently marks the scan CC0; save that page as evidence.
- [ ] Include creator, work title, date, holding institution, licence, and source URL in credits.

### A07 — City of Geneva page

- [ ] Quote/screenshot only the minimum needed to show the research response.
- [ ] Do not treat the page's typography or layout as reusable stock design.
- [ ] Link the page in the description.
- [ ] If using a long/full-page capture, request permission.

### A10 — Smallpox illustration

- [ ] Verify the file's exact date, technique, and licence.
- [ ] Determine whether it depicts vaccination rather than eighteenth-century variolation.
- [ ] Label it `ILLUSTRATIVE` if it is not contemporary with the Genevan cases.
- [ ] Do not visually claim that a depicted procedure happened to any named girl.

## Stock-footage checklist

Pexels and Pixabay provide broad permissions, but each chosen asset still needs a paper trail.

- [ ] Save the exact item page, not only the search URL.
- [ ] Record creator name and asset/clip ID.
- [ ] Save the current [Pexels licence](https://www.pexels.com/license/) or [Pixabay Content License](https://pixabay.com/service/license-summary/).
- [ ] Check whether the asset contains a recognizable person, artwork, logo, trademark, or private location.
- [ ] Avoid using a recognizable child in connection with death, illiteracy, disease, or financial exploitation.
- [ ] Crop all modern devices, writing, cars, signs, light switches, and clothing from supposed period atmosphere.
- [ ] Never call a generic European street “Geneva” unless the clip really is Geneva.
- [ ] Never call reenactment footage archival.
- [ ] Credit creators voluntarily even if attribution is not mandatory; it makes later rights audits easier.
- [ ] Store the unedited original separately from the graded/exported version.

Suggested description credit format:

`Additional footage: [Creator], via Pexels/Pixabay. Full source list: [project link].`

## Generated-asset checklist

- [ ] Keep the original prompt and generation date beside the file.
- [ ] Mark the manifest source as `AI-generated reconstruction`.
- [ ] Add `VISUAL RECONSTRUCTION` on screen whenever a reasonable viewer might mistake it for evidence.
- [ ] Remove accidental pseudo-writing, numbers, signatures, crests, and seals.
- [ ] Do not generate or age a fake “original” 1782 list, contract, certificate, or letter.
- [ ] Do not generate a face for Pernette, Elisabeth-Pauline, Eléonore, Jacqueline, Colombine, Jeanne, or another named girl.
- [ ] Do not use a stock or generated anonymous child as if she were a named historical person.
- [ ] Do not age-progress Anne Audéoud's bust into an invented adult portrait.
- [ ] Add verified names, dates, sums, and quotations in Resolve from typed research notes.
- [ ] Keep generated historical architecture generic; label reconstruction if it anchors a factual scene.
- [ ] Preserve prompt and seed/version metadata where available.

## Historical-integrity checklist

- [ ] October 1784's twenty-nine-girl headcount and January 1782's thirty-name list remain visibly separate.
- [ ] The line “groups of thirty, fifty, and sixty” is not illustrated as one fixed group changing size.
- [ ] Girls are never shown receiving the annuity income merely because their lives measured it.
- [ ] The investor/owner and named life remain separate roles in the diagram.
- [ ] The payment stops at death; the original lump sum does not return.
- [ ] Anne Audéoud is explicitly labelled “wider circle; not the January 1782 list.”
- [ ] The 212,197-livre figure is attributed to Cramer's archival calculation.
- [ ] Elisabeth-Pauline's 1778–1862 dates are sourced; unknown biography stays unknown.
- [ ] No exact death cause, personality, dialogue, room layout, clothing, or family reaction is invented.
- [ ] A document excerpt remains on screen long enough to be read and its source is visible.
- [ ] A generated visual never appears behind the phrase “the archive shows” without a real source also on screen.

## Sensitivity checklist

- [ ] No horror styling, heartbeat, crying-child stock, doll imagery, coffin, candle extinguishing, blood, or jump scare.
- [ ] No mascot appears during Pernette's death or the list of child deaths.
- [ ] No “creepy little girls” framing in thumbnail, music, sound design, or tags.
- [ ] Headcounts feel bureaucratic and uncanny because of the facts, not because children are made visually sinister.
- [ ] Silence and document holds replace melodrama at 8:05–9:35.
- [ ] All girls' names receive equal visual dignity in the final count.

## Final pre-upload audit

- [ ] Every asset visible for more than two seconds has a manifest row.
- [ ] Every external asset has a saved rights receipt.
- [ ] Every archival crop can be traced to its uncropped original.
- [ ] Every on-screen source matches the spoken source.
- [ ] Every generated visual that could be confused with evidence is labelled.
- [ ] Full sources and credits are in the video description.
- [ ] The thumbnail does not use an invented portrait.
- [ ] The final export has been watched once with sound off to catch misleading visual implications.
